About AI Resume Analyzer

AI Resume Analyzer evaluates resumes against job descriptions with ATS scoring, role-aware skill mapping, structured risk detection, and advanced AI suggestions.

Tools & Technologies
  • Frontend: HTML, CSS, JavaScript, Bootstrap
  • Backend: Python, FastAPI, SQLAlchemy, Pydantic
  • Text Extraction: PyPDF, python-docx
  • Scoring Engine: ATS heuristics, keyword coverage, section analysis, impact scoring
  • AI Layer: OpenAI API with deterministic fallback recommendations
  • Database: SQLite
  • Tools: VS Code or PyCharm, GitHub, Uvicorn, virtualenv, Docker-ready workflow

Purpose: help candidates understand job fit, discover missing keywords, and improve resumes with precise, recruiter-friendly feedback.
